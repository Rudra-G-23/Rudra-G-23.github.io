TYPE: [OPEN SOURCE PROJECT]
Name: show-file-tree
Type: Open Source CLI Tool
Description:
Rudra Prasad Bhuyan developed 'show-file-tree', a small, fast command-line tool designed to display beautifully styled file and folder trees in the terminal.
Problem:
Software developers frequently need a clean, readable, and customizable way to visually inspect and share complex project directory structures.
Solution:
Rudra built a Python-based CLI tool that automatically generates visually structured file trees, offering extensive styling and customization options.
Technologies Used:
Rudra utilized Python and modern CLI Development techniques to build this open source utility.
Key Features:
- Rudra's tool generates highly styled and readable file tree outputs.
- The tool natively supports terminal colors and file type icons.
- It can extract and display important metadata for files and folders directly in the tree.
- Rudra ensured the tool remains extremely lightweight and fast to execute.
Project Links:
GitHub: https://github.com/Rudra-G-23/show-file-tree
Documentation: https://rudra-g-23.github.io/show-file-tree/


TYPE: [OPEN SOURCE PROJECT]
Name: find-my-joint
Type: Open Source Data Utility
Description:
Rudra Prasad Bhuyan created 'find-my-joint', a highly useful data utility designed to automatically identify potential join keys across multiple pandas DataFrames.
Problem:
For data scientists, manually finding matching columns between large, unfamiliar datasets is highly time-consuming and heavily error-prone.
Solution:
Rudra developed an automated tool that intelligently scans multiple DataFrames, analyzes their contents, and suggests the best possible join keys automatically.
Technologies Used:
Rudra utilized Python and the Pandas library to develop this open source data engineering utility.
Key Features:
- Rudra's utility automatically detects matching columns and data types across multiple diverse datasets.
- The tool drastically simplifies the complex data merging and joining process for data engineers.
- It significantly reduces the manual effort and time required in the initial stages of data analysis.
Project Links:
GitHub: https://github.com/Rudra-G-23/Find-My-Joint
Documentation: https://rudra-g-23.github.io/Find-My-Joint/
