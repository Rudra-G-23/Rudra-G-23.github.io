TYPE: [OPEN SOURCE PROJECT]
Name: show-file-tree
Type: Open Source CLI Tool
Description:
A small, fast command-line tool to display styled file and folder trees.

Problem:
Developers need a clean and customizable way to visualize project directory structures.

Solution:
Built a CLI tool that generates visually structured file trees with styling and customization options.

Technologies:
Python, CLI Development

Key Features:
- Styled file tree output
- Supports colors and icons
- Displays metadata for files and folders
- Lightweight and fast

TYPE: [OPEN SOURCE PROJECT]
Name: find-my-joint
Type: Open Source Data Utility
Description:
A utility to identify potential join keys across multiple pandas DataFrames.

Problem:
Finding matching columns between datasets is time-consuming and error-prone.

Solution:
Developed a tool that scans multiple DataFrames and suggests possible join keys automatically.

Technologies:
Python, Pandas

Key Features:
- Detects matching columns across datasets
- Simplifies data merging process
- Reduces manual effort in data analysis

Project Link:
GitHub: https://github.com/Rudra-G-23/Find-My-Joint
Docs: https://rudra-g-23.github.io/Find-My-Joint/
