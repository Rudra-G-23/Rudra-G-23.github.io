TYPE: [PROJECT]
Name: Fine-Tuning a Code LLM for Python Fill-in-the-Middle Completion
Type: LLM / Research Project
Description:
Rudra Prasad Bhuyan is fine-tuning a code language model for Python Fill-in-the-Middle (FIM) completion, in collaboration with a PhD researcher at IIT, with a research paper in progress.
Problem:
Small code-completion models need clean, Python-specific Fill-in-the-Middle training data, which does not exist in ready-to-use form.
Solution:
Rudra manually curated a Python-only FIM training dataset from The Stack v3, a 133TB source corpus, through custom filtering and processing, then fine-tuned a model on it.
Technologies Used:
Rudra utilized Python, Hugging Face, Qwen2.5-Coder-0.5B, LLM fine-tuning, and Fill-in-the-Middle (FIM) training for this project.
Key Features:
- Rudra curated a Python-only FIM dataset from a 133TB source corpus using custom filtering.
- Rudra fine-tuned Qwen2.5-Coder-0.5B for Python code completion.
- Rudra published the model and the dataset on Hugging Face.
- Rudra is co-authoring a research paper on this work with a PhD researcher at IIT.
Project Link:
https://huggingface.co/Rudra-G-23
